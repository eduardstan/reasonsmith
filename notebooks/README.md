# Runnable notebooks

Choose by reader, not by number:

- [`01_quickstart_reason_deletion.ipynb`](01_quickstart_reason_deletion.ipynb) — **tool evaluator:** inspect a frozen reason-deletion run and its evidence record.
- [`02_three_systems_three_rungs.ipynb`](02_three_systems_three_rungs.ipynb) — **evidence reader:** compare three system surfaces and the rungs their evidence reaches.
- [`03_bring_your_own_pack_engine.ipynb`](03_bring_your_own_pack_engine.ipynb) — **contributor:** build and install a local pack and engine fixture.
- [`04_one_system_two_jurisdictions.ipynb`](04_one_system_two_jurisdictions.ipynb) — **jurisdiction comparer:** hold one frozen system constant while changing the pack.
- [`05_from_clause_to_formula.ipynb`](05_from_clause_to_formula.ipynb) — **logician:** trace a clause through syntax, atoms, fragments, algebras, and refusals.

The five audience projections in [`docs/audiences.html`](../docs/audiences.html) are the **report** axis: they change what a run shows to a stakeholder. This index is the **reader** axis: it routes a person to the notebook that teaches a path through the tool.
